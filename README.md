## 🎮 Controls

### Keyboard

| Key | Action |
|---|---|
| SPACE | Boost |
| A / D | Rotate |
| ← / → | Rotate |

### Gamepad

| Button | Action |
|---|---|
| Right Button | Boost |
| Left Stick | Rotate |
